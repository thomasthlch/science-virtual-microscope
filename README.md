# 虛擬顯微鏡

小學五年級常識科單元「看不見的世界 — 顯微鏡下的微生物」的靜態教學網頁。學生要親手操作一部虛擬光學顯微鏡，才看得到標本；也可以做「麵包發霉實驗」的公平測試。

適合兩種用法：

- 教師在課室大螢幕或電子白板示範（觸控、大按鈕、可全螢幕）
- 學生在家或小組用平板、手提電腦或手機練習（毋須登入，紀錄只存在該部裝置）

介面語言為香港繁體中文。標本全由程式繪製，不是顯微照片。

## 部署到 GitHub Pages

網站要放在專案站點的子路徑 `/science-virtual-microscope/`。Vite 的 `base` 設為 `./`（相對路徑），因此 JavaScript 和 CSS 在這個子路徑下仍能載入。

1. 把這個儲存庫的預設分支合併到 `main`（工作流程檔在 `.github/workflows/pages.yml`）。
2. 開啟儲存庫的 **Settings → Pages**。
3. 在 **Build and deployment** 將 **Source** 設為 **GitHub Actions**。
4. 推送到 `main` 後，Actions 會執行測試、建置 `dist`，並部署到 GitHub Pages。
5. 網站網址會是：`https://<GitHub 使用者名稱>.github.io/science-virtual-microscope/`

不需要把 Vite `base` 改成絕對路徑，也不需要另設自訂網域。若 Pages 仍顯示舊的「Deploy from a branch」，請改為 GitHub Actions，否則工作流程部署的成品不會被使用。

## 科學內容（五年級程度）

- 總放大倍數＝目鏡 10× × 物鏡（4×、10× 或 40×）。
- 先用低倍尋找影像；粗調焦輪只適宜在 4× 使用。40× 時使用粗調焦輪會出現警示。
- 移動玻片時，影像向相反方向移動；倍數越高，視野越小、細節越大。
- 細菌比酵母菌細小，在 4× 和 10× 看不清楚，要用 40×（總放大 400×）。
- 洋蔥表皮細胞用來和微生物比較：細胞較大，有細胞壁和細胞核。
- 麵包發霉模擬：溫暖、潮濕、沒有防腐劑時較易發霉；雪櫃低溫、乾燥或防腐劑會減慢發霉。公平測試每次只改變一個條件。對照是室溫、濕、沒有防腐劑。

細胞大小經過簡化，方便在螢幕上辨認，但大小次序保持不變。發霉曲線是教學用的定性模型，不是實驗室數據。
